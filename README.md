# gen1recomp-Mod-Gen2-HM-Anywhere
Gen1recomp++ Mod for the Gen2 games.

Im not a coder, so this mod is fully AI "vibe coded".

From my testing, it works fine, however you should use it with some caution.
I had AI create this since its my favorite mod for Gen1, and the existing ones only support the gen1 games.

How it works:

Use owned HMs without teaching them to a Pokemon.
- HMs are available from the START Menu -> HM.
- The HM item must be in the Bag and the normal badge requirement still applies.
- No Pokemon is added to or modified in the party.
- Contextual CUT/SURF/etc. You can just "talk" to water or trees as normal, this also work without a party Pokemon knowing the move.
- FLY uses the native Gold/Silver Fly destination map.

Tested target: Gen1Recomp++ 0.2.20 source layout.
